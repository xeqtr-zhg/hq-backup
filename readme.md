# hq-backup автоматический бэкап сайта на FTP

hq-backup - скрипт, который делает копию сайта (файлы + база данных MySQL) и отправляет её на сторонний FTP-сервер. Нужен только cron в панели хостинга, SSH не требуется.

## Установка

1. Откройте `hq-backup.sh` и заполните настройки (см. ниже).
2. **Переименуйте файл** в длинное случайное имя, например `bk_7f3a9c2e41d8b605.sh`.
3. Загрузите файл в корень сайта.
4. Добавьте в cron (планировщик) в панели хостинга, раз в сутки либо другой нужный интервал, пример:

```
bash /полный/путь/к/корню/сайта/bk_7f3a9c2e41d8b605.sh > /dev/null
```

Полный путь показывает панель хостинга (обычно `/home/логин/...`). Если `bash` не находится, напишите `/bin/bash`.

## Настройки

| Переменная | Что это |
|---|---|
| `DB_HOST` | адрес базы данных (обычно `localhost`) |
| `DB_NAME` | имя базы данных. Если базы нет (статический сайт), оставьте пустым `''` |
| `DB_USER` | пользователь базы данных |
| `DB_PASS` | пароль базы данных |
| `FTP_HOST` | адрес FTP-сервера |
| `FTP_USER` | логин FTP |
| `FTP_PASS` | пароль FTP |
| `FTP_DIR` | папка на FTP (создастся сама), только под бэкапы |
| `KEEP_COPIES` | сколько копий хранить, старые перезаписываются по кругу |

Пароли не должны содержать символ `'`.

## Важно

- **Не публикуйте заполненный файл и не коммитьте пароли в Git.**
- В файле лежат пароли, поэтому имя должно быть случайным, а список файлов в папке сайта не должен открываться в браузере.
- Раз в месяц проверяйте, что на FTP лежат свежие копии нормального размера, и пробуйте восстановить сайт.
